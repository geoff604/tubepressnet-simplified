== Change Log file ==

Changes in 4.4.0

* Added %tp_thumbnail_best% template tag that resolves the highest
  available thumbnail resolution (maxres > standard > high > medium
  > default) using client-side resolution cascade.
* Added thumbnail_best custom field (tp_thumbnail_best) populated on
  import alongside the existing tp_thumbnail field.
* Updated AJAX import endpoint and post-creation function to accept,
  sanitize, and store the new thumbnail_best URL.
* Updated Setup screen custom fields list and template tag reference
  to document %tp_thumbnail_best%.

Changes in 4.3.0

* Implemented Zero-Backend-Token architecture: Video metadata is fetched directly in the browser via client-side OAuth 2.0.
* Google API tokens and secrets never touch or reside on the WordPress backend.
* Completely removed server-side Composer vendor autoload and Google PHP Client SDK dependencies.
* Added Google OAuth Client ID field and step-by-step setup documentation in TubePress Setup screen.
* Modernized Import by ID with AJAX progress and live post view/edit links.

Changes in 4.2.1

* Security hardening: Added CSRF protection using WordPress nonces on all admin forms.
* Security hardening: Added explicit capability checks (manage_options) and replaced legacy numeric user levels.
* Security hardening: Prevented SQL injection vulnerabilities using $wpdb->prepare().
* Security hardening: Added output escaping (esc_attr, esc_html, esc_url, esc_textarea) to prevent XSS.
* Enhanced OAuth token handling with secure transients and SameSite cookie attributes.
* Lazy-loaded Google API client dependencies and added dependency check admin notice.

Changes in 4.2.0

* Change to client-side auth to avoid storing secret on server
* Rewrote this Wordpress plugin so that it uses OAUTH2 request from the browser,
so no client secret will need to be stored on the web server.
